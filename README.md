# Ушло в дым

Калькулятор курильщика в одном HTML-файле. Вы указываете, с какого времени и сколько курите, а сайт показывает результат:

- **штучно**: все выкуренные сигареты по одной, по годам;
- **пачками**: каждая пачка значком, плюс высота стопки из всех пачек рядом с известными зданиями;
- **кучей**: горка из всех сигарет рядом с человеком вашего роста, её объём, вес и площадь;
- **в длину**: линия из сигарет на схеме БАМа и «лестница масштабов» от футбольного поля до Луны;
- **в деньгах**: сколько потрачено (с учётом подорожания, если указать старую цену), что можно было купить, сколько было бы на вкладе;
- **время и здоровье**, а также что изменится, если бросить сегодня.

## Как запустить

Откройте `index.html` в браузере. Сборка, сервер и зависимости не нужны: всё считается в браузере, данные никуда не отправляются.

Чтобы получить ссылку для друзей, включите GitHub Pages (Settings → Pages → Deploy from a branch) — сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`.

Введённые данные сохраняются в адресе страницы, так что результатом можно поделиться ссылкой.

По умолчанию сайт светлый; кнопка в правом верхнем углу включает тёмную тему (выбор запоминается).

## Допущения

Все расчёты приблизительные. Константы (длина и диаметр сигареты, плотность кучи, длительность перекура и т.д.) перечислены в блоке «Как считаем» внизу страницы и в начале скрипта в `index.html`.
